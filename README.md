# Лабораторна робота № 8. Підключення до бази даних та виконання основних операцій

**Мета:** здобути практичні навички роботи з базами даних у мові програмування Python. Навчитися підключатися до бази даних, виконувати базові операції, такі як створення таблиць, вставка даних, оновлення даних, видалення даних та вибірка даних. Ознайомитися з основними принципами роботи з базами даних та зрозуміти важливість використання мови SQL для взаємодії з ними.

## Завдання для всіх варіантів

1.  Необхідно встановити систему керування базами даних (СКБД) на свій комп’ютер, наприклад, PostgreSQL, MySQL, SQLite або іншу за вибором та створити нову базу даних з довільним ім’ям.
2.  Використовуючи відповідну бібліотеку Python (наприклад, `psycopg2` для PostgreSQL, `mysql-connector-python` для MySQL, `sqlite3` для SQLite), написати код, який встановлює з’єднання з створеною базою даних.
3.  Написати SQL-запит для створення таблиці у своїй базі даних. Таблиця повинна містити принаймні три колонки з різними типами даних (наприклад, INTEGER, VARCHAR, DATE). Одна з колонок повинна бути первинним ключем.
4.  Написати код для вставки принаймні п’яти рядків даних у створену таблицю. Дані повинні відповідати типам даних колонок.
5.  Написати код для оновлення даних в одному або декількох рядках таблиці за певною умовою.
6.  Написати код для видалення одного або декількох рядків з таблиці за певною умовою.
7.  Написати код для вибірки даних з таблиці з використанням різних умов та сортування. Наприклад, вибрати всі дані з таблиці, вибрати дані за певною умовою, відсортувати дані за певною колонкою.

## Приклад виконання завдання

1.  **Встановити СУБД PostgreSQL та створити базу даних з назвою «university».**
2.  **Підключитися до бази даних «university» за допомогою бібліотеки `psycopg2`.**
3.  **Створити таблицю «students»** з колонками: `id` (INTEGER, PRIMARY KEY), `name` (VARCHAR(255)), `age` (INTEGER), `admission_date` (DATE).
4.  **Вставити п’ять рядків даних** про студентів у таблицю «students».
5.  **Оновити вік студента** з ім’ям «John Doe».
6.  **Видалити студента** з найдавнішою датою вступу.
7.  **Вибрати всіх студентів**, ім’я яких починається на «А», і відсортувати їх за віком у порядку зростання.

Весь код для прикладу знаходиться у файлі [`src/lab8.py`](src/lab8.py).
